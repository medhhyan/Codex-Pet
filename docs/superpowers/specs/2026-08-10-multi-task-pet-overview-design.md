# 多任务桌宠总览设计

## 目标

将桌宠从单一状态指示器扩展为多任务总览：熊猫图形表示所有 Codex 任务的总体状态，展开区域列出每个已知任务。

## 状态规则

1. 任一任务进行中时，总体为“搬砖中”（橙色）。
2. 没有进行中任务、但有任务在过去 8 秒内完成时，总体为“任务完成”（绿色）。
3. 其余情况为“休息中”（蓝色）。
4. 等待授权或等待输入的任务在列表中标为“等待中”，不计入进行中。

## 展开界面

- 顶部显示熊猫、总体状态与进行中数量。
- 右侧环形分布图按橙色进行中、绿色完成、蓝色等待汇总任务数量。
- 每条任务显示标题（超长截断）、状态、短说明与相对时间。
- 继续保留本周使用与“最近同步”时间；删除今日 Token。

## 数据与容错

- 从本地 Codex 会话日志按任务/回合 ID 聚合最新事件。
- 仅使用明确的 `task_started`、`task_complete` 及等待事件；缺失或不完整记录不影响其他任务。
- 周使用显示最近一次写入本地的 `rate_limits.primary.used_percent` 及该条记录时间。

## 验收

- 两项进行中、一项完成时总体必须为“搬砖中”，列表分别正确显示。
- 没有进行中任务时，完成状态最多显示 8 秒。
- 无法读取 Token 时不显示今日 Token，不阻断任务状态。
