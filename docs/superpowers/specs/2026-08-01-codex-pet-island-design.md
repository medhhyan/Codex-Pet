# Codex 桌宠灵动岛设计

## 目标

在 Windows 上提供一个轻量、透明、始终置顶的 Tauri + React 桌宠，实时呈现 Codex 的真实任务状态、周使用比例和今日 Token 用量。

## 视觉与资源

灵动岛采用深黑背景、圆角玻璃质感和紧凑布局。主角为用户提供参考图中的连帽衫熊猫程序员：工作时保持冷脸专注；完成和休息时可开心。

- `src/assets/pets/working.png`：冷脸熊猫敲笔记本；橙色状态提示。
- `src/assets/pets/completed.png`：开心熊猫举带勾咖啡杯；绿色状态提示。
- `src/assets/pets/resting.png`：开心熊猫趴在合上的笔记本旁；蓝色状态提示。

三张图为透明 PNG，桌宠收起状态的高度至少 92px，熊猫仍保持清楚可辨。可选的键鼠粒子/波纹动态默认关闭。

## 架构

Tauri 后端（Rust）提供单实例锁、窗口与托盘控制、开机自启、本地数据读取和状态监控。React 前端只渲染状态、用量、宠物动画与交互。两者通过 Tauri commands/events 通信。

### 状态数据适配器

本地 `CodexDataAdapter` 以 Codex 用户数据目录中的会话索引、状态库和事件日志为数据源。启动时探测可读取的版本化来源；事件增量更新优先，轮询仅作兜底。

状态机只依据明确的真实任务执行事件：

1. 收到任务/工具执行开始或持续执行证据，切为 `working`（搬砖中）。
2. 收到结束/完成证据，切为 `completed`（任务完成），记录一个 8 秒可见窗口。
3. 8 秒到期、用户查看完成提示、或无法确认执行时，切为 `resting`（休息中）。

仅检测到 Codex 进程、窗口打开、等待用户输入、心跳或静态会话内容时，绝不进入 `working`。若来源格式不兼容或权限不足，状态回退为 `resting` 并在用量区显示“暂未同步”，而非猜测。

### 用量

适配器从可验证的本地使用统计读取：本周额度使用比例和当日 Token。数据带更新时间；超过 5 分钟未刷新时标记为“同步延迟”。未知字段保持空状态，不显示估算数值。

## 交互与窗口

- 无边框、透明、置顶窗口；拖动非按钮区域移动。
- 展开显示状态、周用量、今日 Token 和控制；收起仍显示熊猫、状态色与简要用量。
- 最小化/关闭操作可隐藏到托盘；托盘菜单提供恢复、展开/收起、动态效果开关与退出。
- 单实例插件保证重复启动时聚焦既有窗口。
- 登录自启保存为用户设置，可从设置或托盘切换。

## 容错与验证

启动时验证资源、监测源和自启/托盘初始化。监测源不可用不影响窗口与托盘；显示明确降级状态。测试覆盖状态机中的等待输入、工作、完成的 8 秒窗口、超时回休息、数据缺失，以及单实例和窗口命令。

## 非目标

首版不控制 Codex、不向云端上传本地会话内容，也不以操作系统键鼠活动来推断 Codex 是否在工作。
