# Codex Panda Pet Assets

These three 1254 × 1254 RGBA PNGs are the visual states for the floating
Codex pet. They were generated from the user-provided programmer-panda
reference, then converted from a solid chroma-key green background to
transparent pixels.

| State | Final asset | Intended expression |
| --- | --- | --- |
| Working | `working.png` | Serious panda in a black hoodie typing on a laptop |
| Completed | `completed.png` | Happy panda with a green-check coffee mug |
| Resting | `resting.png` | Content, eyes-closed panda leaning on a closed laptop |

The original generation files are intentionally ignored by Git as
`*-source.png`; they remain locally to make later visual adjustments possible.

Generation direction: retain the reference's dark hoodie panda, bold
black-ink poster illustration, and clean small-size silhouette. Do not add
text, logos, or borders. The application supplies the blue, green, and orange
state indicators in the UI.
